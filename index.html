如何获取小红书 Cookie?
  1. 电脑浏览器打开 小红书官网 并登录。
  2. 按下键盘 F12 键，或鼠标右键点击页面选择“检查”打开开发者工具。
  3. 点击顶部的 Network (网络) 标签，然后刷新网页。
  4. 在左侧列表中点击任意一个请求（如 user 或 profile 等）。
  5. 在右侧找到 Request Headers (请求头) 下的 Cookie 字段，粘贴到上方输入框中。
如何获取用户主页链接?
  1. 访问 小红书官网 并进入目标博主主页。
  2. 直接复制浏览器顶部的地址栏链接。
